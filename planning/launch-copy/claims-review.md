## How to use this list

1. **Mark each row** keep, reword (with the new wording), remove, or needs a source. Rows in the same program can be reviewed together.
2. **Start with rows that have entries in the Health words column.** The column shows matches from a keyword screen (risk, reduce, prevent, blood pressure, glucose, pregnancy, injury, pain, supplement, and so on). It's a reading aid, not a verdict: a row marked "-" can still make a claim, and a marked row can be harmless.
3. **Sections 1, 2 (clinical keys), 5 and 7 are fully inventoried.** Every prose string is listed. In sections 3 and 4, non-clinical rows appear only when they hit the keyword screen. Section 6 lists every supplement `why`, `caution` and interaction note. Section 8 lists every cue on the 48 Care library exercises.
4. **Out of scope here:** set and rep prescriptions in clinical programs (BL-01 to BL-06 fix the automatic volume and RPE first, and the reviewer should check the prescriptions alongside this list); AI system prompts (they're instructions to the model, not copy shown to users); What's New entries.
